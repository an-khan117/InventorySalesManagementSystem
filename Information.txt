## 2. What Is SQL?

SQL stands for Structured Query Language. It is used to create databases and tables, insert data, retrieve data, update records, delete records, and manage database transactions.

## 3. Database Creation and Basic Commands

```sql
CREATE DATABASE inventory_sales_db;

SHOW DATABASES;

USE inventory_sales_db;

SELECT DATABASE();

SHOW TABLES;

SELECT VERSION();
```

Explanation:
- `CREATE DATABASE` creates a new database.
- `SHOW DATABASES` displays available databases.
- `USE` selects the database.
- `SELECT DATABASE()` shows the currently selected database.
- `SHOW TABLES` displays tables in the selected database.
- `SELECT VERSION()` displays the database server version.

To delete a database, use:

```sql
DROP DATABASE inventory_sales_db;
```

Warning: This permanently deletes the database and its tables. Do not run it on your project database unless you intentionally want to delete everything.

## 5. Creating a Table — Example

The following is a learning example. Check your existing schema before running it, because your project may already contain the table.

```sql
CREATE TABLE example_products (
    product_id INT PRIMARY KEY AUTO_INCREMENT,
    product_name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    stock_quantity INT DEFAULT 0
);
```

Explanation:
- `INT`: Stores integer values.
- `VARCHAR(100)`: Stores text up to 100 characters.
- `DECIMAL(10,2)`: Stores numbers with two decimal places.
- `PRIMARY KEY`: Uniquely identifies each record.
- `AUTO_INCREMENT`: Automatically generates an ID.
- `NOT NULL`: Does not allow an empty value.
- `DEFAULT 0`: Uses zero when no value is supplied.

## 12. Aggregate Functions

Aggregate functions calculate results from multiple rows.

Count all products:

```sql
SELECT COUNT(*) AS total_products
FROM products;
```

Calculate total stock:

```sql
SELECT COALESCE(SUM(stock_quantity), 0) AS total_stock
FROM products;
```

Find the average selling price:

```sql
SELECT AVG(selling_price) AS average_price
FROM products;
```

Find the lowest price:

```sql
SELECT MIN(selling_price) AS minimum_price
FROM products;
```

Find the highest price:

```sql
SELECT MAX(selling_price) AS maximum_price
FROM products;
```

`COALESCE` returns zero if the SUM result is NULL.

## 13. GROUP BY and HAVING

`GROUP BY` groups rows with the same value. `HAVING` filters grouped results.

Example: Count products in each category.

```sql
SELECT category_id, COUNT(*) AS product_count
FROM products
GROUP BY category_id;
```

Show categories with more than five products:

```sql
SELECT category_id, COUNT(*) AS product_count
FROM products
GROUP BY category_id
HAVING COUNT(*) > 5;
```

## 14. JOIN Operations

JOIN combines information from related tables.

### INNER JOIN

Returns only records that match in both tables.

```sql
SELECT p.*, c.*
FROM products AS p
INNER JOIN categories AS c
ON p.category_id = c.category_id;
```

This example assumes that both tables use the indicated column names.

### LEFT JOIN

Returns all rows from the left table and matching rows from the right table. If no match exists, right-table columns contain NULL.

```sql
SELECT p.*, c.*
FROM products AS p
LEFT JOIN categories AS c
ON p.category_id = c.category_id;
```

### RIGHT JOIN

Returns all rows from the right table and matching rows from the left table.

```sql
SELECT p.*, c.*
FROM products AS p
RIGHT JOIN categories AS c
ON p.category_id = c.category_id;
```

Important: These are examples. The actual JOIN type used by your Flask application must be confirmed by checking `app.py` and your table structure.

## 16. Constraints

Constraints help maintain correct and reliable data.

- `PRIMARY KEY`: Uniquely identifies a row.
- `FOREIGN KEY`: Connects related tables.
- `NOT NULL`: Prevents NULL values in a column.
- `UNIQUE`: Prevents duplicate values.
- `DEFAULT`: Sets a default value.
- `CHECK`: Enforces a condition, subject to database version and configuration.

Example:

```sql
CREATE TABLE example_categories (
    category_id INT PRIMARY KEY AUTO_INCREMENT,
    category_name VARCHAR(100) NOT NULL UNIQUE
);
```

Example foreign key:

```sql
CREATE TABLE example_items (
    item_id INT PRIMARY KEY AUTO_INCREMENT,
    category_id INT,
    FOREIGN KEY (category_id)
        REFERENCES example_categories(category_id)
);
```

These are demonstration tables, not instructions to replace your current schema.

## 18. Transactions

A transaction groups database operations into a unit of work.

```sql
START TRANSACTION;

UPDATE example_products
SET stock_quantity = stock_quantity - 1
WHERE product_id = 1;

COMMIT;
```

`COMMIT` saves the transaction.

To cancel uncommitted changes:

```sql
START TRANSACTION;

UPDATE example_products
SET stock_quantity = stock_quantity - 1
WHERE product_id = 1;

ROLLBACK;
```

`ROLLBACK` cancels changes made during the current transaction, provided they have not already been committed and the storage engine supports transactions.

Create a savepoint:

```sql
START TRANSACTION;

SAVEPOINT first_step;

UPDATE example_products
SET stock_quantity = stock_quantity + 5
WHERE product_id = 1;

ROLLBACK TO first_step;

COMMIT;
```

These are transaction demonstrations, not confirmation that the current project uses transactions in its code.

## 22. DDL, DML, DQL, DCL and TCL

**DDL — Data Definition Language:** Used to define database structures.

Examples: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.

**DML — Data Manipulation Language:** Used to modify data.

Examples: `INSERT`, `UPDATE`, `DELETE`.

**DQL — Data Query Language:** Used to retrieve data.

Example: `SELECT`.

**DCL — Data Control Language:** Used to control database permissions.

Examples: `GRANT`, `REVOKE`.

**TCL — Transaction Control Language:** Used to manage transactions.

Examples: `COMMIT`, `ROLLBACK`, `SAVEPOINT`.
